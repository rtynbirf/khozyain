# ДОКУМЕНТ · ЗАКОН ДОМА (аккаунт-уровень)

## 1. Дом — один автомат

Аккаунт `rtynbirf` — дом. Каждый репозиторий — комната. Дом как целое описывается
конечным автоматом **M = (Q, Σ, δ, q₀, F)**:

- **Q** = {ПОКОЙ, РАЗВЕДКА, РЕМОНТ, СТРОЙКА, УБОРКА, ДОКЛАД, REJECT};
- **q₀** = ПОКОЙ (дом чист, тревог нет);
- **F** = {ПОКОЙ} — единственное терминальное состояние цикла: сеанс работы окончен
  только в ПОКОЕ;
- **REJECT** — попытка выйти из дома мимо УБОРКИ; из REJECT есть ровно один
  переход — назад в УБОРКУ.

## 2. Алфавит событий Σ

| Событие | Детектор (машинный) |
|---|---|
| `MANDATE` | Хозяин выдал мандат (чат/issue) |
| `RED_MAIN` | последний прогон workflow на default-ветке = failure |
| `DEAD_TRIGGER` | ветка в `on.push.branches` не существует (тихая смерть автоматики) |
| `OPEN_STATE` | открытые issues/PR вне реестра законных состояний |
| `UNREAD_NOTIFICATION` | `GET /notifications` ≠ 0 на выходе сессии |
| `STATE_CLOSED` | состояние из реестра закрыто и верифицировано зелёным прогоном |
| `CLEAN_DONE` | `khozyain_sweep.py`: 0 тревог |
| `LOGGED` | запись TH-* внесена в ворклог |

## 3. Функция переходов δ (основные дуги)

```
ПОКОЙ   --MANDATE-->            РАЗВЕДКА
РАЗВЕДКА --RED_MAIN|DEAD_TRIGGER|OPEN_STATE-->  РЕМОНТ
РАЗВЕДКА --чисто-->              СТРОЙКА
РЕМОНТ  --STATE_CLOSED-->       УБОРКА
РЕМОНТ  --не могу закрыть-->    РЕЕСТР (legit_open_states, дедлайн) → УБОРКА
СТРОЙКА --изделие записано-->   УБОРКА
УБОРКА  --CLEAN_DONE-->         ДОКЛАД
УБОРКА  --UNREAD_NOTIFICATION-->УБОРКА   (самоперевод: гасить можно только
                                          после фиксации состояния в HOUSE_STATE)
ДОКЛАД  --LOGGED-->             ПОКОЙ
любое   --выход мимо УБОРКИ-->  REJECT
REJECT  --возврат-->            УБОРКА
```

**Свойство автомата (проверено домом 2026-11-10):** из любого состояния существует
путь в ПОКОЙ конечной длины; выход из дома определён только из ПОКОЯ.

## 4. Guard-ы переходов

- **G1 (РЕМОНТ):** ремонт не меняет чужое без мандата; живая волна другого агента
  не трогается — состояние уходит в реестр с дедлайном 24 ч, а не в силовой мерж.
- **G2 (РЕМОНТ):** диагноз раньше лекарства; воспроизведение локально раньше пуша.
- **G3 (УБОРКА):** нотификация гасится только когда её состояние закрыто ИЛИ
  внесено в HOUSE_STATE (бумажка умирает, знание остаётся).
- **G4 (СТРОЙКА):** аддитивность; одна мысль — один коммит; формат доктрины 04 §3.
- **G5 (ДОКЛАД):** отчёт = сделано / не получилось / решения в рамках мандата /
  что нужно от Хозяина. Скрыть провал хуже провала.

## 7. Что остаётся человеку

Только то, что автомату запрещено: ценности, деньги, доступы, вердикты верификатора.
Всё остальное — δ-пути. Двенадцать дефолтов «всё решаю сам» — в `domovoy-ritual`;
аккаунт-уровневые дефолты дополняют их: смена видимости, удаление репо, слияние
чужих PR-верификаторов — только по прямому мандату Хозяина.
